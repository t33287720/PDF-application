PDF Tools
100%

點擊「開啟」載入 PDF 或圖片

也可以直接把檔案拖進視窗（可多選）；圖片會轉成 PDF 頁面

輸出選項

套用於儲存、擷取等所有輸出的檔案

開啟檔案需要密碼，並禁止複製文字
其他中繼資料（建立軟體、時間等）都會清除

分割 PDF

頁碼依目前的頁面順序；輸出選項也會套用到每個檔案

書籤（目錄）

編輯後的書籤會套用於儲存、擷取、分割等輸出的 PDF；刪除頁面時其書籤會一併略過

裁切頁面

自四邊裁掉指定寬度（以目前旋轉後所見的方向為準）。裁切只會縮小可視範圍，原內容仍留在檔案內，不能用來移除機密資訊。

轉成圖片

每頁輸出一張圖片；輸出選項中的浮水印、頁碼也會套用
